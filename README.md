# Meteo

Web app meteo personale per l'iPhone: media pesata di sei modelli (ICON-2I di ItaliaMeteo-ARPAE, ICON-D2, MeteoSvizzera ICON-CH2, ICON-EU, ECMWF, ECMWF AI) via Open-Meteo, con indice di fiducia, pioggia ogni 15 minuti, radar della Protezione Civile.

Sito: https://mediograve.github.io/meteo/ — su iPhone: Safari → Condividi → Aggiungi alla schermata Home.

Luoghi e ultima previsione sono salvati solo sul telefono (localStorage).
